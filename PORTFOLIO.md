# Danke Studios portfolio

Open `index.html` in a modern browser. No build, installation or server is required. Upload `index.html`, `styles.css`, `script.js` and the original image files together to any static website host to publish.

The page includes a responsive layout, seven portfolio designs with category filters and a keyboard-accessible image dialog, studio introduction, services, Academy channel and contact links. Original images and README.MD are preserved. Google Fonts is optional; local system fonts work without an internet connection.

Contact sources: email, social links and Academy channel come from README.MD. The WhatsApp number +255 710 496 426 appears on NewMonth2.jpg.jpeg. Verify ownership and availability of these accounts before publishing. WhatsApp opens a draft for the visitor to send; email opens their mail application.

Edit portfolio cards in index.html. Each card's data-category controls filtering; data-title and data-description populate its image dialog. Update the displayed total when adding or removing projects. Styling is in styles.css, interactions in script.js.

Manual review: open at desktop and mobile widths; check mobile menu, all four filters, opening and closing images (including Escape), keyboard navigation, contact links and image loading. The site has no backend or contact submission service.
